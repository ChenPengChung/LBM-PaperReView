## Key Equations/Ideas

### Core Concept: Reconstruction vs. Interpolation
- **Standard reconstruction:** cell averages → polynomial → cell-based values
- **Point interpolation:** cell averages → primitive function → arbitrary point values

### Fourth-Order WENO Interpolation
The interpolation formula at target position $x_0$ can be expressed as:
$$u(x_0) = \sum_{i} \omega_i(x_0) p_i(x_0)$$

where:
- $\omega_i(x_0)$ are the **position-dependent linear weights** (not constant)
- $p_i(x_0)$ are polynomial reconstructions on stencils
- The weights must be recalculated for each target position $x_0$

### Key Innovation: Position-Dependent Weights
Unlike standard WENO reconstruction where weights depend only on smoothness indicators, interpolation requires:
$$\omega_i(x_0) = \text{linear weights as explicit functions of } x_0$$

This allows:
- Optimal accuracy for each arbitrary position
- Fourth-order accuracy maintained across the domain
- Proper weighting of stencils based on proximity to target point
