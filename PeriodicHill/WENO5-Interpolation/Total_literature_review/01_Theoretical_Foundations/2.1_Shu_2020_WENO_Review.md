## Key Concepts

- **WENO Reconstruction vs Interpolation**: Critical distinction between reconstructing cell averages vs interpolating point values
- **Function Value Interpolation**: WENO methods for approximating function values at arbitrary locations from discrete point values
- **Non-Uniform Grid Handling**: Extension of WENO interpolation to non-uniform mesh structures
- **Essentially Non-Oscillatory Properties**: Theoretical framework for maintaining stability without spurious oscillations

## Key Equations/Ideas

- **WENO Interpolation Formula**:
  $$u(x) \approx \sum_{r=0}^{k-1} d_r w_r(x) p_r(x)$$
  where $d_r$ are ideal weights and $w_r(x)$ are smoothness-indicator-based weights varying with location

- **Smoothness Indicators**: Used to automatically adjust weights based on local regularity

- **Generalization Beyond Half-Grid Points**: Framework extended from $x_{i+1/2}$ to arbitrary target points $\sigma \in [0,1]$
