## Key Equations/Ideas

### Shallow Water Equations
$$\frac{\partial h}{\partial t} + \frac{\partial (hu)}{\partial x} + \frac{\partial (hv)}{\partial y} = 0$$
$$\frac{\partial (hu)}{\partial t} + \frac{\partial (hu^2 + \frac{1}{2}gh^2)}{\partial x} + \frac{\partial (huv)}{\partial y} = -gh\frac{\partial b}{\partial x}$$
$$\frac{\partial (hv)}{\partial t} + \frac{\partial (huv)}{\partial x} + \frac{\partial (hv^2 + \frac{1}{2}gh^2)}{\partial y} = -gh\frac{\partial b}{\partial y}$$

where $h$ is water depth, $(u,v)$ are velocities, $b$ is bottom topography, and $g$ is gravity.

### Well-Balanced Property
A scheme maintains the well-balanced property if it preserves the "lake at rest" solution:
$$u = v = 0, \quad h + b = \text{constant}$$

For interpolation-based schemes, this requires:
$$\frac{\partial h}{\partial t}\bigg|_{well-balanced} = 0, \quad \frac{\partial u}{\partial t}\bigg|_{well-balanced} = 0$$

even when topography varies.

### WENO Interpolation for Finite Differences
Point value approximation at $x_i$:
$$u_i = \sum_{k=0}^{r-1} \omega_k^{WENO} u_k^{(interp)}(x_i)$$

where $u_k^{(interp)}(x_i)$ are polynomial approximations constructed from cell averages.

The derivative at grid point:
$$\frac{\partial u}{\partial x}\bigg|_{x_i} = \sum_{k=0}^{r-1} \omega_k^{WENO} \frac{d u_k}{dx}\bigg|_{x_i}$$

### Maintaining Well-Balanced Property
The key is balancing the pressure gradient with topography gradient:
$$\frac{\partial (h + b)}{\partial x} = 0 \quad \Rightarrow \quad \frac{\partial h}{\partial x} = -\frac{\partial b}{\partial x}$$

This must be discretized consistently:
$$\frac{h_i - h_{i-1}}{\Delta x} = -\frac{b_i - b_{i-1}}{\Delta x}$$

for all grid points where this is true in the exact solution.

## Critical Insights
1. **Interpolation-based WENO is compatible with well-balanced properties**
2. **Careful discretization of source terms** is essential for maintaining conservation
3. **The method naturally handles irregular topography** without additional measures
4. **High-order accuracy is preserved** even with the constraint of well-balanced property
5. **Dry regions (h → 0) require special treatment** to maintain positivity and stability
