## Key Equations/Ideas

### Departure Point Determination
特征线追踪方程：
$$\frac{d\mathbf{x}}{dt} = \mathbf{v}(\mathbf{x}, t)$$

使用改进的Runge-Kutta方法求解出发点 $\mathbf{x}_i^*$：
$$\mathbf{x}_i^* = \mathbf{x}_i - \sum_{stage} b_s \mathbf{k}_s$$

其中 $\mathbf{k}_s$ 是各阶段的斜率。

### Non-Half-Grid Point Interpolation
对于出发点 $x_j^* \in (x_r, x_{r+1})$，定义局部坐标：
$$\xi = \frac{x_j^* - x_r}{\Delta x}, \quad \xi \in (0, 1)$$

### Smoothness Indicators at Arbitrary Points
在非半网格点处的光滑度指标：
$$\beta_r(\xi) = \int_{I_r} \sum_{l=1}^{k} (p_r^{(l)}(\xi))^2 (x - x_r)^{2(l-1)} dx$$

其中 $p_r^{(l)}(\xi)$ 是区间 $I_r$ 上第五阶多项式的第 $l$ 阶导数在点 $\xi$ 处的值。

### Adaptive WENO Weights
根据点位置 $\xi$ 自适应计算权重：
$$\tilde{\omega}_r(\xi) = \frac{c_r(\xi)}{(\epsilon + \beta_r(\xi))^p}$$

其中线性权重 $c_r(\xi)$ 是关于 $\xi$ 的多项式函数。

### Linear Weights for Fifth-Order WENO
第五阶WENO的线性权重（在 $\xi = 1/2$ 处）：
$$c_0 = 1/10, \quad c_1 = 6/10, \quad c_2 = 3/10$$

对于一般的 $\xi$，权重自适应调整以保持多项式精度。

### WENO Reconstruction Formula
在出发点处的重构：
$$f(x_j^*) = \sum_{r=0}^{2} \omega_r(\xi) p_r^{(5)}(x_j^*)$$

其中 $\omega_r(\xi) = \tilde{\omega}_r(\xi) / \sum_s \tilde{\omega}_s(\xi)$。

### Stability and Accuracy
误差估计：
$$\|f(x_j^*) - f_{\text{exact}}(x_j^*)\| = O(\Delta x^5)$$

在光滑区域。在间断附近，WENO权重自动增强光滑区间的贡献。
